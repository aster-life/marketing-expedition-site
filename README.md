# 行銷遠征網站

「行銷遠征」的正式靜態網站部署版本。首頁整合捲動控制影片、Three.js 3D 場景與互動探險地圖。

## 本機預覽

在此目錄執行：

```powershell
python -m http.server 8765
```

再開啟 <http://127.0.0.1:8765/>。

## Zeabur 部署

本儲存庫只有瀏覽器可直接執行的靜態檔案。Zeabur 連接 GitHub 儲存庫後會自動以 Static 模式部署，`index.html` 為首頁；後續推送至 `main` 會觸發重新部署。

## 來源與更新

設計與製作原始檔保留在本機專案的 `網站設計` 目錄。本儲存庫不收錄 Blender 工程檔、Python 虛擬環境、測試截圖或審閱壓縮檔。

## 四區近景版本（2026-09-17）

地圖四區可從建築外觀進入獨立的近景空間，點選三件展品以查看筆記及前往相關內容。四區筆記保留頂部配圖，桌機在左側閱讀，手機在場景下方閱讀。近景使用既有本機模型與材質，加入柔和側光並調整構圖；前三幕影片與 3D 維持既有版本。

每次僅保留一個近景 renderer，切區時釋放上一個；靜止時停止重繪。所有依賴均隨本儲存庫部署。首頁是手工維護的成品，不應使用早期 `build_site.py` 重建覆蓋。
